simulator-use vs mobile-mcp

Pick mobile-mcp to drive real iOS and Android devices, over USB or on Mobile Next Cloud, with the same tools as simulators and emulators. (mobile-mcp README)

Pick simulator-use to build and test the Xcode project with the same tool, and for taps whose answer says what changed on screen. (simulator-use README, mobile-mcp README)

Measured on one Mac, a sign-in took mobile-mcp 6.95 s and 980 tokens read (est.); simulator-use 4.66 s (second run 7.13 s) and 194 tokens read (est.).

What each does

From each tool's own README, license and docs, read on October 31, 2026.

mobile-mcpsimulator-use
LicenseApache 2.0; built on mobilecli, which is under the Functional Source License 1.1 (mobile-mcp LICENSE, mobile-mcp README, mobilecli LICENSE)MIT (simulator-use LICENSE)
Builds the appNo; it installs an .app, .ipa, .apk or .zip (mobile-mcp README)Yes: builds the Xcode project, installs and launches it (app_run) (simulator-use README)
Runs testsNone in its README (mobile-mcp README)XCTest and XCUITest, case by case (tests_run) (simulator-use README)
Screen as textOne line per element, with refs (mobile-mcp README)One line per element: kind, label, #id, state and position (simulator-use README)
How it tapsBy ref from its element list, or at x,y coordinates (mobile-mcp README)By #id or label, or at @x,y (simulator-use README)
Cloud optionMobile Next Cloud: real iOS and Android devices (mobile-mcp README)A NoMac cloud iPhone (simulator-use cloud start), billed per minute (simulator-use README)
Needs besides XcodeNode 20 and the Xcode command line tools. On iOS, mobilecli's on-device agent is required for touch input and UI tree inspection (mobile-mcp README, mobilecli README)Node 20. Its engine is built on AXe's frameworks, which it bundles (simulator-use README)

Where mobile-mcp is better

  • Real devices as well as simulators and emulators, iOS and Android. (mobile-mcp README)
  • Mobile Next Cloud: real iOS and Android devices from the same tools. (mobile-mcp README)
  • Tapping a button: 0.77 s against simulator-use's 1.17 s (second run 1.10 s).

Where simulator-use is better

  • Builds the Xcode project and runs its XCTest and XCUITest cases; mobile-mcp installs an app built elsewhere. (simulator-use README, mobile-mcp README)
  • MIT throughout, the AXe and IDB frameworks it bundles included; mobile-mcp is built on mobilecli, which is under the Functional Source License 1.1. (simulator-use README, mobile-mcp README, mobilecli LICENSE)
  • Tokens read per sign-in (est.): 194 tokens against mobile-mcp's 980 tokens.
  • Signing in, batched: 3.69 s (second run 5.36 s) against mobile-mcp's 6.91 s.
  • Reading the screen: 0.21 s (second run 0.22 s) against mobile-mcp's 0.42 s.
  • Tokens per screen read (est.): 72 tokens against mobile-mcp's 375 tokens.
  • Typing into a field: 1.22 s (second run 2.28 s) against mobile-mcp's 2.52 s.
  • Tool list in the agent's context (est.): 2,443 tokens against mobile-mcp's 7,129 tokens.
  • Setup and first read after a boot: 14.77 s (second run 4.09 s) against mobile-mcp's 21.59 s.
  • A tap's answer held the new status text in 20 of 20 taps, mobile-mcp's in 0 of 20.

A measured difference is listed only when it holds against both of simulator-use's runs by at least 5%.
