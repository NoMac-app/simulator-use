      Tools
      
Twelve tools. One list for MCP and the CLI.

      
Short descriptions, under 4,000 tokens with the instructions, and every step checked: typed text is read back, a tap that changes nothing is reported, and the first failing step stops the rest.

      

        
app_run
Builds the Xcode project, installs and launches it, answers with the first screen. Errors as file:line.

        
ui_look
The screen as text: kind, label, #id, state, @x,y. A screenshot or a full-size PNG when asked.

        
ui_act
Taps, fills, scrolls, swipes and waits, in the words ui_look prints, and answers with what changed.

        
tests_run
XCTest and XCUITest, each case as it finishes, each failure as file:line. Zero tests is an error.

        
app_control
Install, launch, deep links, permissions, location, push, appearance, locale and a clean status bar.

        
app_logs
The app's print output and its log lines, grep and wait_for, and crashes with the crashing thread.

        
screen_record
A video of the screen, to show a person what happened.

        
devices · device_use
The Simulators and Xcodes on the Mac; choose one, boot it, dark mode, a clean status bar.

        
job_status
A build past 40 s becomes a job: follow it until it ends, with its last lines meanwhile.

        
job_cancel
Stops a build that is no longer needed.

        
cloud
Moves every tool to a cloud iPhone and back: start, status, extend, stop, and run for CI.

        
the CLI
simulator-use look, act, run, test: the same tools from a shell, taught by a skill under 2 KB.

      Cloud
      
No Mac? The same tools on a cloud iPhone.

      
From Linux, Windows, a cloud agent or CI: one command moves every tool to an iPhone Simulator on a Mac with Xcode, run by NoMac. Only the files the phone lacks are sent, and builds stay incremental.

      

        
$ npx simulator-use cloud start  # a phone in seconds
$ npx simulator-use run          # send, build, launch
$ npx simulator-use look         # every tool runs there
$ npx simulator-use cloud stop   # back to this machine

# CI in one line: build, run, test, screenshot, video
$ npx simulator-use cloud run . --tests

      How it works
      
Nothing to build into your app.

      
No test runner to compile and no SDK in the app: simulator-use reads what iOS's accessibility already knows, through the Simulator's own frameworks, so the first call is as fast as the rest.
