Tools

    
One list for MCP and the CLI. Every step is checked: typed text is read back, and a tap that changes nothing says so.

    

      
app_run
Build, install and launch. Errors as file:line.

      
ui_look
The screen as text. A screenshot, or a full-size PNG.

      
ui_act
Tap, fill, scroll, swipe, wait. Answers with what changed.

      
tests_run
XCTest and XCUITest, case by case.

      
app_control
Install, deep links, permissions, location, push, locale.

      
app_logs
Print output, system logs and crashes.

      
screen_record
A video of the screen.

      
devices, device_use
Pick and boot a Simulator.

      
job_status, job_cancel
Follow or stop a long build.

      
cloud
Run every tool on a cloud iPhone instead.

    

  


  

    
Install

    
Needs a Mac with Xcode and Node 20. Nothing leaves your Mac unless you turn on cloud.

No Mac? Use a cloud iPhone.

    
The same tools from Linux, Windows or CI, on an iPhone Simulator run by NoMac.

    

      
npx simulator-use cloud start
npx simulator-use run      # send, build, launch
npx simulator-use look
npx simulator-use cloud stop

# CI in one line
npx simulator-use cloud run . --tests
